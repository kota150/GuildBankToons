# Changelog: Forever - Guild Bank Toons

### Added
- First version: shares designated bank characters' bags, bank and gold over guild addon chat, with guildmates relaying copies so the bank stays visible while the bank character is offline.
- Browse window with search and Bags/Bank filters, item tooltips showing guild bank counts, and Ctrl-click to whisper the bank character.
- Discord companion script that posts each bank character to a webhook message and keeps it updated.
